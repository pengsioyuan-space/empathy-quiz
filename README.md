# 共情能力测试（IRI-C）

一个独立的纯前端共情能力测试网站。视觉风格沿用用户选定的暖色、留白和单题卡片设计，但与原“恋爱安全感”项目完全分离。

## 测试内容

- 中文版人际反应指针量表（IRI-C）22题
- 0～4五级选项
- 第2、5、10、11、14题反向计分
- 四个维度：观点采择（PT）、想象代入（FS）、共情关注（EC）、个人忧伤（PD）
- 浏览器本地保存答题进度，不收集姓名或其他个人信息

参考问卷星页面把“姓名”作为第1题，因此实际只展示了21道量表题。本项目补回标准量表第12题“看完戏或电影之后，我会觉得自己好像是剧中的某一个角色”，确保四个维度和22题结构完整。

## 本地预览

```powershell
python -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。

## GitHub Pages 部署

1. 在 GitHub 新建一个空仓库，例如 `empathy-quiz`。
2. 将本目录中的 `index.html`、`styles.css`、`app.js`、`README.md` 和 `.gitignore` 提交到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. 选择 **Deploy from a branch**，使用 `main` 分支和 `/ (root)` 目录。

发布地址通常为 `https://你的用户名.github.io/empathy-quiz/`。

## 说明

本测试用于自我观察与交流，不构成心理诊断。IRI-C 的“个人忧伤”衡量在紧张人际情境中的焦虑与不适，高分需要单独理解，不能简单等同于“共情能力更强”。
